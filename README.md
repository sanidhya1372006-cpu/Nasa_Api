A web application designed to fetch and showcase astronomical data, space imagery, and mission details directly using **NASA's Open APIs**. Built to present complex space data with a clean, modern interactive interface.

## 🌐 Live Demo
Check out the live app here: **[Live NASA Explorer](https://sanidhya1372006-cpu.github.io/Nasa_Api/)**

---

## 🚀 Key Features

- 🌌 **APOD Integration:** Displays NASA's Astronomy Picture of the Day with descriptions.
- 🔭 **Interactive Space Data:** Explores data feeds from NASA's public archives.
- 📱 **Responsive Glassmorphism UI:** Modern dark space aesthetic optimized across mobile, tablet, and desktop screens.
- ⚡ **Asynchronous Data Handling:** Clean Fetch API calls with dynamic rendering.

---

## 🛠️ Technology Stack

- **HTML5:** Modern document structure.
- **CSS3:** Custom space-themed styling, animations, and flexible layouts.
- **JavaScript (ES6):** Async/Await, REST API integration, dynamic DOM manipulation.
- **GitHub Pages:** Deployment and hosting.
